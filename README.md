# זמנית

אפליקציית PWA לניהול אירועים עם לוח עברי. חישובי התאריך והמרת התאריכים מבוססים על `@internationalized/date` (Apache-2.0); ממשק לוח השנה מעוצב עבור האפליקציה.

## פיתוח מקומי

נדרשת התקנת Node.js.

```sh
npm install
npm run dev
```

פתחי את `http://localhost:8000`. הפורט והכתובת נשמרים כדי שהאירועים המקומיים שכבר נשמרו באותו מקור יישארו זמינים. אם שרת מקומי קודם כבר משתמש בפורט 8000, עצרי אותו עם `Ctrl+C` לפני הפעלת Vite.

## בנייה והרצה

```sh
npm run build
npm run preview
```

הקבצים המוכנים להפצה נמצאים בתיקיית `dist/`. נדרשת הגשה דרך HTTPS בפריסה, או דרך `localhost` בפיתוח, עבור התקנת ה־PWA ושימוש ב־Service Worker.
